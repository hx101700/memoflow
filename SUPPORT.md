# Support

For installation and usage questions, start with the [usage guide](skills/asr-transcription/references/usage.md) and [troubleshooting guide](skills/asr-transcription/references/errors.md).

Use [Discussions](https://github.com/hx101700/memoflow/discussions) for questions, workflows, and feature ideas. Use [Issues](https://github.com/hx101700/memoflow/issues) for reproducible bugs.

When reporting a problem, include:

- Windows version and architecture;
- package name and release version;
- the step that failed;
- the exact redacted error message;
- whether the failure is repeatable.

Never include API keys, login URLs, private recordings, transcript content, or personal paths.
