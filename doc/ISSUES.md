# 当前问题与限制

本文记录仍存在的不足和运行限制。Python 源码在 `skills/asr-transcription/scripts/asr_runtime/`，前端源码在 `frontend/`；实际验证范围见 [ACCEPTANCE](ACCEPTANCE.md)，工作与发布状态见 [STATUS](STATUS.md)。

下表只保留当前边界和未解决事项。代码与文档的本轮核对见[REVIEW](REVIEW.md)，已完成的历史修正通过Git追溯。

## 功能不足

| 问题 | 证据与影响 | 处理方式 |
| --- | --- | --- |
| BL登录依赖Windows桌面环境 | 再次实际对话确认首次调用缺少require_escalated，重试才使用正常权限；当前令牌对照读取也区分出受限/正常进程 | 首次调用即申请正常桌面权限，代码在启动BL前拒绝受限令牌；不把浏览器失败归因为Key无效 |
| 成功记录恢复入口缺失 | transcription 在 JSON_READY 写入失败时保留当次结果，但磁盘可能滞后；export 要求已保存成功记录及摘要 | 保留回执和 JSON，先检查记录保存原因，不补签摘要或重新识别 |
| 下载速度受当时链路影响 | 短时文件采样只能比较当前两条链路，不能保证整个依赖下载期间速度不变 | 持续查看进度；中断由pip有限恢复，最终失败后换另一来源，仍失败时查看安装日志 |
| 历史任务列表缺失 | CLI 状态查询与重导要求确切 job_id | 保留交接回执中的确切 job_id；用户确认时使用预览复制的 session_id，不按文件时间猜测任务 |
| 环境检查不覆盖窗口可见性 | doctor 检查 Python、Node、BL 与依赖，不能证明原生目录窗口能显示 | 在实际 Windows 交互桌面验证选择、取消与焦点 |

## 运行限制

| 限制 | 对使用的影响 |
| --- | --- |
| 指定平台与联网安装 | 需要 Windows x64 CPython 3.12、Node/npm；依赖锁和二进制包按此平台维护，安装速度受网络影响 |
| 工作目录隔离 | 工作目录和保存位置须位于 Skill 安装目录外，每个工作目录的环境与凭据分别准备 |
| 已交接任务不可修改 | 返回修改只发生在编辑会话；确认交接后配置固定，需要新识别时明确配置新任务，保留旧记录 |
| 模型切换后的待执行配置 | 新识别只接受当前固定模型；其它模型的配置在执行占用前被拒绝，需要重新确认。历史状态和成功结果的本地重导仍可用 |
| 未交接输入的生命周期 | 编辑会话从打开起有效两小时，不按操作延长。同一服务可恢复内存预览，未提交编辑不自动保存；会话结束后不保证恢复，原文件与已保存凭据保留 |
| 不完整 BL 安装 | 安装器保留非空或不完整目录并报告冲突；需核对具体残留后处理，保留用户凭据与任务 |
| 原生窗口依赖桌面环境 | 工具隔离或桌面权限可能影响窗口显示；按工具权限流程在正常桌面启动，不能用脚本绕过隔离 |
| BL 2.1.0浏览器调用仍有上游缺陷 | 当前通过仅限登录的Node预加载适配转交完整URL，在第一次开页前避免cmd拆参；BL升级时需重新核对并优先采用官方修复 |
| 每任务一次执行尝试 | 本地准备失败也保留执行占用；失败后不通过删除记录重跑同一编号 |
| 重导覆盖同名成品 | 人工校对文档先另存；重新导出基于原始 JSON，不能保留成品中的人工修改 |
| 云端状态可见性 | BL 完整模式未稳定提供 task_id；提交超时不能证明未受理，本机停止不能取消云端；当前没有恢复查询或云端取消入口 |
| 大文件资源开销 | 固定 BL 上传实现会整文件读入内存；本机合成媒体测试不能覆盖全部实际大文件情形，不另写上传器或自动切片 |
| 用户文件的 Git 保护 | 用户工作目录可能属于其他仓库，依赖、凭据和结果不能假定受本仓库忽略规则保护，提交前需检查实际路径 |
| 页面语言与输出格式 | 中英文切换针对配置页面和已登记的本机提示；音频语言另行选择，CLI 提示和导出文档仍沿用当前格式 |
| 界面偏好作用域 | 语言与主题保存在当前网页来源的 localStorage；每次服务使用的端口可能变化，因此不承诺跨服务会话继承偏好 |
| 会议总结尚未实现 | 第一阶段只交付转写文档供校对；第二阶段需另行定义校对输入、样式示例及总结要求 |
