## 复现入口

```powershell
.venv\Scripts\python.exe -B -X utf8 -m unittest discover -s tests -t .
.venv\Scripts\python.exe -B -X utf8 -m mypy --config-file mypy.ini --no-incremental
npm run test:web
npm run build:web
npm run test:browser
```

本机 BL 合约使用固定 CLI、127.0.0.1 模拟服务与合成凭据。有效期使用受控时钟；强制退出使用本例进程；不操作用户原录音、真实凭据或已安装副本。

## 验证边界

- 本机检查不替代新 Codex 对话的实际安装及完整人机使用。
- 本轮未复测真实云端识别、真实登录、原生文件/目录窗口人工操作、Office 逐页视觉或全新联网安装。
- 进程停止时不能执行 finally。回收发生在下次 serve，且仅覆盖归属明确、满足相应生命周期的文件。
- 旧版无 PID 临时文件、系统 Temp、归属不明的残留和 BL/pip/npm 自有缓存保留。
- 当前没有后台清理服务或自动重传。正式任务、执行占用和结果按原协议保留。
