## 保留的设计及理由

| 设计 | 当前消费者与取舍 |
| --- | --- |
| Session锁、Skill共享/独占读取、execution目录占用 | 分别保护同一编辑状态、文件更新与活动进程、一次云端执行，不能因都叫“锁”就合并或删除 |
| 预览完整摘要、交接size/mtime、执行前完整摘要 | 分别建立用户核对基线、轻量交接检查、确认实际上传内容；符合直接读取原录音的约束 |
| bootstrap／doctor共用探针 | 正常成功不追加doctor，主动诊断仍需要相同的目标环境检查；没有第二套安装器 |
| 三种子进程入口 | 安装进度、BL隐私/结果、普通有限命令的输出与停止语义不同，强行合并会增加分支 |
| 本地输入校验 | 支撑预览、表格错误位置、模型规格与媒体处理；BL继续负责云端鉴权/上传/轮询，不复刻同等云端能力 |
| JSON_READY与文档交付分离 | 单格式或本地保存失败不改写为识别失败、不触发重传，支持明确的部分交付 |
| 原子写入、来源摘要与定点回收 | 消费者是配置交接、重导来源与旧文件保留；未知归属保留而非扩大删除范围 |
| 现有Vue用例与Element Plus组件 | 状态和可操作条件有单一推导入口，组件公开能力已覆盖需求；没有拆分更多组件层或引入状态机库的理由 |

文档测试实际生成/回读Office并核对文本、时间、标签、公式类型与样式；媒体测试使用真实编码/解码及不同声道的样本贡献；发布和回收测试核对文件字节及真实进程。它们有实际行为证据，不只断言函数调用次数。

## 命名、注释与规约

保留用户明确要求的中文函数职责说明和类型，但注释只写动作、结果、约束或原因，不写成逐次修改日志。沿用现有snake_case、camelCase和业务术语；没有全量重命名或格式化。`session_id`与`job_id`、执行状态与交付状态、网页语言与音频语言继续区分。

从AGENTS移出的内容是易变版本、具体函数链、安装参数和完整使用步骤，它们分别归源码/锁文件、DEVELOPMENT及references；固定模型、单文件、私有运行时、确认方式、一次执行、隐私、Git授权与发行边界仍保留。已经完成的截图占位要求改为维护现有截图与示意说明。

新增依赖仅用于开发：Mermaid使图稿可按锁重建，PyYAML供官方Skill格式校验。新增`render_uml.ts`与`check_docs.py`分别解决已发生的图风格漂移和失效链接，均不进入用户包。
