## 当前协议

编辑会话固定两小时，填写与预览不产生任务。用户从预览页复制含 session_id 的确认消息后，代码交接唯一不可变 job；裸“继续”不能代选会话。必要登录后继续同一任务，失败不自动重试。

音频直接读取原路径，Excel 内存解析；只有声道合并产生处理文件。热词与上下文只在“确认并预览”检查；错误绑定稳定行键，重复组剩两条以上继续标红。指定 API Key 直接执行，无需控制台登录。正常关闭及下次开页仅回收确定归属的暂存，保留正式凭据、用户原文件、任务和结果。
